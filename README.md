# CAN Report

A firefighter study skill tree: read a node, mark it read, pass its quiz to unlock what comes next. Earn Class Points and ranks, write reflections, and flag content you think is wrong with a Challenge Coin.

Open the site and it works offline once loaded (installable as an app). Progress stays in your browser only; nothing is sent anywhere.

> Study aid only. Department SOPs, instructors and current manufacturer manuals take priority.
